# herbal-cookbook-website
A web-based Herbal Cookbook developed using HTML, CSS, and JavaScript that showcases herbal recipes, healthy ingredients, and natural cooking ideas through an interactive user interface.

Project Overview
*Herbal Cookbook is designed to:
*Display herbal recipes
*Promote healthy cooking habits
*Provide clean and interactive UI
*Improve front-end web development skills

Objectives
✔ Build a responsive recipe website
✔ Showcase herbal and healthy recipes
✔ Improve UI/UX using CSS
✔ Add interaction using JavaScript
✔ Practice front-end web development

Features
*Herbal recipe listings
*Clean and modern design
*Responsive layout
*Interactive elements using JavaScript
*Easy navigation
*Recipe sections with ingredients and instructions

Technologies Used
*HTML5
*CSS3
*JavaScript
*Responsive Web Design
